Hubbly

Hubbly is a full-stack web application that allows users to share and engage with posts, inspired by platforms like Reddit. The app features voting, filtering by topics, and dynamic content. It is built using React for the front end and Express.js for the back end.

🌐 Deployed Version

👉 View the live app here: hubblynews.netlify.app

📝 Description

Hubbly is a responsive, user-friendly web app where users can:
	•	Browse articles by topic
	•	Read, upvote/downvote, and comment on posts
	•	Filter content and explore engaging discussions

The front end is built with React and uses Axios to interact with a RESTful API. The project emphasizes clean UI, modular components, and an intuitive user experience.

👉 Back End GitHub Repo: https://articles-backend-project.onrender.com/api

⚙️ Minimum Node Version

This project requires Node.js version 18.x or higher.
You can check your current version by running the following command in your terminal:

node –version

🚀 Getting Started Locally

Follow the steps below to run the project locally:
	1.	Clone the repository: https://github.com/AstridKMina/hubbly.git
	2.	Navigate into the project directory: cd hubbly
	3.	Install dependencies: npm install
	4.	Start the development server: npm run dev
	5.	Visit http://localhost:5173 in your browser to see the app running locally.

💡 Make sure the back-end server is also running if you are testing the full-stack functionality.
